# Healthcare Insights

Analysis of about 7,000 patient records from a hospital in Madras, India,
comparing patient outcomes by attending physician. Completed during a data
science internship at GUVI (Dec 2024 – Mar 2025).

## Question
Do patient outcomes differ by attending physician, and where should the
hospital focus to improve care?

## Tools
- Python (pandas) for cleaning and analysis
- SQL (SQLite) for querying
- Streamlit for the interactive dashboard

## Files
- `healthcare_insights_final.py`: final analysis and Streamlit dashboard
- `Healthcare_Insights_Draft.ipynb`: exploratory notebook
- `requirements.txt`: Python dependencies
- `Healtcare-Dataset.xlsx`: source data

## How to run
pip install -r requirements.txt
streamlit run healthcare_insights_final.py
